## 实现决策

- 使用文档推荐的 LLM → QueryPlan → 服务端 SQL 编译路线。自然语言理解与 SQL 执行严格分离。
- 核心技术栈为 Vue 3 / TypeScript / ECharts、Python FastAPI / Pydantic / SQLAlchemy / SQLGlot、MySQL 8.4 配置。
- 本机实际是 Linux/WSL、Python 3.10.12；不是规划假设的原生 Windows。补装项目内 Node.js 22.16.0、Python 虚拟环境与浏览器依赖。
- 该环境没有可用的 MySQL 服务，Docker Desktop 未开启本发行版集成。本次运行的是独立 SQLite 开发数据和应用库；这不等于完成 MySQL 集成验证。
- 未提供模型 API Key，默认使用明确标注的规则演示模式。真实 API 适配器已实现并通过模拟 HTTP 协议测试，但没有声称真实模型调用成功。
- 真实 API 模式失败时不会偷偷回退规则模式；不把规则演示延迟与准确性作为模型指标。

## 已取得的验证证据

- 生成 3,000 张订单、9,000 条明细，固定种子 42；所有订单金额与明细合计一致。标准 100,000 订单配置已提供，未将小数据演示冒称标准规模性能测试。
- 后端测试 **63 项通过**：订单/明细聚合、零值与空值、四表关联、同名客户、支付/下单时间、地区快照、HAVING、布尔筛选、时间补零、Top N 完整分母、参数绑定、危险 SQL 拒绝、跨用户隔离、CSRF、幂等、快照过期、取消回调、报告转义及模型非法输出拒绝。
- `npm run build --prefix frontend`：TypeScript 校验与生产构建通过。
- Python 依赖一致性检查通过；依赖精确版本在 `requirements.lock` 和 `frontend/package-lock.json` 中记录。
- 图表依赖初次审计发现旧版本存在已公开问题，升级到 ECharts 6.1.0 后安装时审计结果为 0 个已知漏洞。再次独立审计曾因网络中断失败，因此不将网络失败作为安全通过证据。
- 真实 Chromium 主流程：登录 → 客户排名 → 华北地区追问 → 切换表格 → Word/PDF 下载 → 390px 移动端检查，通过且无页面 JavaScript 错误。
- `artifacts/browser/` 保存桌面/移动端截图、下载报告及浏览器完成耗时；计时包括首屏表格与图表可用，数值仅反映本机规则演示。
- `evaluation/report_smoke.py` 实际生成汇总、空结果、占比、趋势、1,000 行明细五种场景，各 Word/PDF 共 10 份；五份 Word 的全部表格行与对应快照逐格一致，并包含 SQL 附录。
- PDF 已提取中文文字并渲染图片检查；客户排名报告中文、图表、金额及表格正常。1,000 行明细 PDF 共 54 页，第 2 页检查表头重复、中文和列边界正常。十次报告生成/下载实测为 4.101～5.338 秒，仅为本机小样本，不能当作正式 P95 结论。Word 检查了 OOXML 可编辑表格与内嵌图片，未使用 Office/LibreOffice 对所有 Word 版式逐页渲染。

## 明确限制和仍待验证事项

1. **MySQL 尚未实连验证**：MySQL 方言编译已有回归测试；仍需在 MySQL 8.4 检查六表权限、执行结果、索引、超时/取消与连接恢复。取消实现使用同账号控制连接发送 `KILL QUERY`，以服务器执行时限兜底；其真实行为必须在部署环境验证。[MySQL 官方 KILL 说明](https://dev.mysql.com/doc/refman/8.4/en/kill.html)
2. **模型能力尚未验收**：没有真实模型选型对比、100 次可行性调用、300/60/80 冻结题集、三份数据快照盲测或 1/5 并发每组 1,000 次性能报告。91% 与 3 秒均为待测目标，不是交付时已经达到的结论。
3. **小型本机部署**：API 单进程、导出单工作进程。会话忙碌与登录限流使用进程内状态，不支持横向多实例；导出任务和结果持久化在应用库。
4. **原型范围**：管理界面只读展示语义目录与脱敏审计；模型/数据源通过环境变量配置，没有在线配置编辑、完整评测看板或数据库迁移框架。
5. **受控查询边界**：复杂商品条件在无法确保同一明细粒度时明确拒绝；商品类别客单价要求澄清。没有开放任意 SQL、任意窗口函数、退款利润库存、同比环比或预测。
6. **图表与报告**：超过 50 个数据点明确显示表格；大于 500 个完整聚合分组拒绝，明细最多保存 1,000 行。报告测试目前 10 份，尚未完成原规划 20 场景/40 份全覆盖与导出 P95 验收。
7. **中文字体**：PDF 使用本地字体嵌入；Word 设置中文字体名称，目标设备需安装相应字体或可替代中文字体。没有承诺跨 Office 版本像素一致。
8. 测试框架目前有一个 Starlette 关于 httpx TestClient 未来迁移的弃用提示；测试通过，不影响生产 HTTP 客户端。
