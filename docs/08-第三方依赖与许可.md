# 第三方依赖与许可

直接依赖版本以 `requirements.lock` 和 `frontend/package-lock.json` 为准。以下许可证名称来自本次安装包的元数据；完整版权通知与传递依赖许可证仍保留在各依赖包的 dist-info / LICENSE 中，发布时应一并保留。

| 组件 | 许可证 |
|---|---|
| FastAPI、Pydantic、pydantic-settings | MIT |
| SQLAlchemy、PyMySQL、SQLGlot | MIT |
| python-docx | MIT |
| Uvicorn、HTTPX | BSD-3-Clause |
| Playwright | Apache-2.0 |
| Vue、Vite、TypeScript | 以安装包 LICENSE 为准（Vue/Vite 为 MIT，TypeScript 为 Apache-2.0） |
| Apache ECharts | Apache-2.0 |
| pytest、Ruff | MIT |
| Noto Sans CJK SC | SIL Open Font License 1.1 |

中文字体来源：`notofonts/noto-cjk` 仓库的 `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`。字体和其 LICENSE 下载到 `artifacts/fonts/`，未复制为自有源码。Chromium 的第三方版权与许可证随 Playwright 下载的浏览器分发保留。

MySQL 容器是独立运行组件，镜像和 MySQL 的许可由上游提供；本仓库不重新分发 MySQL 二进制。
